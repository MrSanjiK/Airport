# Surface brief — Home (index.html)

## Scope and mode
Home page of the Media Port site. Mode: **Persuade**. Network detail pages (Airport, Korzinka, HoReCa, Regions) extend this world later.

## Audience, job, action
Marketing directors / media buyers in Uzbekistan and international brands. Job: see where the screens are, who sees them, what they cost; build a media plan. Primary action: "Media-plan tuzish" (calculator → inquiry). Secondary: phone / Telegram / WhatsApp.

## Proof and content
Deck figures only (PRODUCT.md). Real placement photos from the PDFs. Prices public with 3 / 6 / 12-month ladder, excl. VAT.

## Constraints
Nine languages incl. RTL Arabic, CJK, Korean. Flags in the language switcher (user instruction). Apple-style frosted navigation; every control custom with crafted hover/motion (user instruction). Reduced-motion and no-WebGL fallbacks.

## Approved composition
